# Mean Teacher Baseline

This directory is reserved for the Mean Teacher reference implementation used as a baseline.

The baseline code is adapted from the codebase used in "Fourier-Enhanced Student-Teacher Distillation for Semi-supervised Medical Image Segmentation" (IUKM 2025, Springer, https://doi.org/10.1007/978-981-96-4606-7_10) and is included only for reference and reproducibility comparisons.

The proposed reliability-aware consistency method is implemented in `../../our/Reliability_MT.ipynb`.
